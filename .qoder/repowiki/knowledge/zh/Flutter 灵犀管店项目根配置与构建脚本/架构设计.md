作为 Flutter 应用的根模块，本目录不包含业务源码，而是由三类文件构成项目骨架：
- 包定义与依赖：`pubspec.yaml` 声明应用名 `flutter_deer`、版本 `1.0.1+112`、SDK 约束（Dart ≥3.4 / Flutter ≥3.19），并通过 `dependency_overrides` 将 `scrollable_positioned_list`、`record_linux` 等第三方包替换为本地 `packages/` 下的补丁版本；`flutter.assets` 枚举 `assets/data/`、`assets/images/*`、`assets/svg/` 等静态资源及自定义字体 `RobotoThin`。
- 开发规范：`analysis_options.yaml` 统一 Dart 静态分析规则，`devtools_options.yaml` 配置 DevTools 行为。
- 构建流水线：Windows PowerShell 脚本提供本地与云端协作的构建链——`build_apk.ps1` 执行 `flutter build apk --split-per-abi --target-platform android-arm64,android-arm` 并输出带完整版本号（含 buildNumber）的 `ylx_boss_flutter_<ver>_64.apk` / `_32.apk`；`build_ipa.ps1` 负责 Codemagic 云产出的 `.ipa` 重命名与安装指引；`codemagic.yaml` 在 macOS 云机上通过 `--no-codesign` 生成未签名 iOS 包，并由 Sideloadly 在 Windows 端免费签名安装；`download_flutter.ps1` 从 Google 或清华镜像下载 Flutter SDK；`get_short_path.ps1` 用于解析 JDK 短路径以规避 Windows 长路径问题。
依赖方向单向向外：脚本仅读取 `pubspec.yaml` 的版本字段，不反向引用 Dart 源码。
